# LeadHunter — Telegram-бот для поиска лидов и контента

Ищет людей и компании, которым нужны **сайты, Telegram-боты, ИИ-автоматизация, ИИ-мультики/ролики**, во всех
доступных местах и присылает их вам в Telegram: с оценкой, выжимкой от ИИ, бюджетом, контактом и готовым
черновиком первого сообщения. **Работает сразу после `BOT_TOKEN` — без единого API-ключа.**

Вторая половина — **контент-фабрика**: ИИ пишет посты, карусели, сценарии видео и лид-магниты под ваш профиль,
учится на ваших правках, рендерит слайды и видео, публикует в Telegram / VK / Threads / Instagram / YouTube Shorts
по расписанию, а лендинг лид-магнита превращает заявки обратно в горячих лидов. Ниша любая — меняется тремя
настройками (`/profile`, `/phrases_set`, `/kw_add`), движок универсальный.

## Как это работает

```
 Threads (без логина) ─┐
 Kwork «Запросы» ──────┤
 Weblancer ────────────┤
 Freelance.ru ─────────┤        ┌──────────┐   ┌──────────┐   ┌─────────┐   ┌─────────┐   ┌──────────┐
 FL.ru (RSS) ──────────┼──────▶ │  дедуп   │─▶ │ игнор-   │─▶ │ словарь │─▶ │   ИИ    │─▶ │ карточка │
 Яндекс.Карты (без API)┤        │ id+текст │   │ листы    │   │ скоринг │   │ GPT и т.п│   │ в Telegram│
 Аудит сайтов ─────────┤        └──────────┘   └──────────┘   └─────────┘   └─────────┘   └────┬─────┘
 Telegram-чаты ────────┤                                                        ▲               │
 hh.ru / VK / Instagram┘                                       ваши отметки «🔥 / 🚫»       вебхук в CRM
```

1. **Источники** работают параллельно, каждый со своим интервалом; Telegram — в реальном времени.
   Источники без API ходят на сайты «как человек»: TLS-отпечаток Chrome, паузы 4–30 с между запросами,
   только в рабочие часы, при капче — стоп и алерт вам в бота, опционально через прокси.
2. **Дедуп**: один и тот же запрос, разосланный по 10 чатам с разными ссылками и эмодзи, придёт один раз.
3. **Игнор-листы**: шумные чаты (кнопка «🔇 Чат в игнор» под карточкой) и авторы-спамеры (`/block @user`).
4. **Свежесть**: старше `MAX_AGE_HOURS` (48ч) — не показываем.
5. **Словарный скоринг** (мгновенный, бесплатный): тема +2/слово, намерение +3/слово, стоп-слова −3/слово,
   слова сгруппированы по услугам (сайт / бот / автоматизация / мультик).
6. **ИИ** (если задан `OPENAI_API_KEY`) смотрит всё, где есть хотя бы одно слово по теме, и возвращает:
   лид/не лид, балл 0–10, услугу, срочность, бюджет, выжимку и **черновик первого сообщения**.
   В промпт подставляется **профиль студии** (`/profile`) и **ваши отметки** 🔥/🚫 как примеры.
   `/phrases_gen` — ИИ генерирует поисковые фразы под ваш профиль.
7. **Карточка**: источник, балл, услуга, срочность 🔴🟡🟢, выжимка, текст, автор, контакт, бюджет, ссылка.
   Кнопки: ✅ Написал · 🔥 Горячий · 🚫 Не лид · ✍️ Черновик · 📨 Отправить с аккаунта · 🔇 Чат в игнор.
8. **Дайджест** раз в день, **CSV-экспорт**, **вебхук** в n8n / Make / Google Sheets / amoCRM.

## Источники

### Работают без ключей (включены по умолчанию)

| Источник | Что ищет | Проверено |
|---|---|---|
| **Threads** | Поиск по фразам-намерениям без логина — 15–25 свежих постов на фразу из Relay-кэша страницы | ✅ |
| **Kwork «Запросы»** | Покупатели сами пишут, что им нужно; категория «Разработка и IT» + все | ✅ |
| **Weblancer** | Открытые проекты из Next.js-payload страницы | ✅ |
| **Freelance.ru** | Лента заданий по словам «сайт», «бот», «нейросеть»… | ✅ |
| **FL.ru** | RSS заказов | ✅ |
| **Яндекс.Карты** | Поиск «стоматология Тула» → 25 организаций с сайтом/телефоном/соцсетями прямо в HTML. **Без сайта** → лид с телефоном | ✅ |
| **Аудит сайтов** | У кого сайт есть — проверяем: не открывается / без HTTPS / не мобильный / заглушка → лид на редизайн | ✅ |
| **hh.ru** | Проектные вакансии (публичный API, нужен `HH_USER_AGENT` с почтой) | блокирует IP дата-центров |
| **Поисковики** | `site:vc.ru "нужен сайт"` через DuckDuckGo | медленно, часы задержки |

### Нужен аккаунт или ключ

| Источник | Что нужно |
|---|---|
| **Telegram-чаты** | `TG_API_ID`/`TG_API_HASH` с my.telegram.org + `python -m leadhunter.tg_login`. Realtime по всем группам аккаунта; `/tg_find`, `/tg_join` из бота |
| **Instagram** | Отдельный аккаунт: `python -m leadhunter.browser.login instagram` (логин в окне браузера один раз) + `IG_WEB_ENABLED=true`. Посты по хэштегам через внутренний API со своими куками. **Риск бана** — прокси, 3 хэштега в проход |
| **VK** | Бесплатный user-токен → `newsfeed.search` по фразам |
| **Threads / Instagram / Яндекс (официальные API)** | Если токен задан — используется вместо парсинга |

## Запуск

```bash
cp .env.example .env            # минимум — BOT_TOKEN
pip install .
patchright install chromium     # только если нужен Instagram
python -m leadhunter.tg_login   # только если подключаете Telegram-чаты
python -m leadhunter
```

Docker:

```bash
docker compose up -d
docker compose run --rm -it leadhunter python -m leadhunter.tg_login      # Telegram-аккаунт, один раз
```

Напишите боту `/start` — первый написавший становится владельцем (или задайте `OWNER_IDS`).

**Ниша одной командой**: `/niche` — список пресетов (студия сайтов, недвижимость, юрист, ремонт, бьюти, фитнес,
стоматология, авто, обучение, маркетплейсы). `/niche realtor` меняет профиль для ИИ, фразы поиска, словарь тем и
контент-рубрики. Своя ниша — `/profile`, `/phrases_set`, `/kw_add`.

**Ключ ИИ**: один `GEMINI_API_KEY` (aistudio.google.com, бесплатный лимит на тексты и озвучку) закрывает всё —
скоринг лидов, тексты, озвучку, картинки и ИИ-видео. Подписка ChatGPT Plus для API **не подходит**.

Браузерный логин в Instagram делается на компьютере с экраном (`python -m leadhunter.browser.login instagram`),
затем папка `data/profiles/instagram` копируется на сервер.

## Рабочая группа с темами и команда

1. Создайте группу в Telegram, включите в настройках **«Темы»**.
2. Добавьте бота админом с правом **«Управление темами»**.
3. Напишите в группе `/setup_group` — бот создаст темы и начнёт слать лидов туда:

| Тема | Что попадает |
|---|---|
| 🔥 Горячие | балл ≥ `HOT_SCORE` или срочность высокая — **со звуком** |
| 🌐 Сайты · 🤖 Боты · ⚙️ Автоматизация · 🎬 Мультики | по услуге, тихо |
| 🗺 Бизнес без сайта · 🩺 Аудит сайтов | холодная база из карт |
| 📋 Биржи | Kwork, Weblancer, FL.ru, Freelance.ru, hh |
| 📊 Отчёты · ⚠️ Здоровье | дайджесты, воронка по понедельникам, алерты источников |

**Команда**: любой участник группы нажимает «👋 Беру» — лид закрепляется за ним, двое не напишут одному клиенту.
Дальше статусы ✅ Написал → 💬 Ответил → 🤝 Сделка / ❌ Отказ. **SLA**: горячий лид никто не взял 10 минут —
пинг в «Горячие». **Follow-up**: написали, клиент молчит 24 ч — напоминание с кнопками. `/team` — кто сколько
взял и закрыл, медиана «появился → взяли» и доля взятых за 5 минут (это и есть главная метрика конверсии).

## Mini App — кабинет внутри Telegram

Строгий чёрно-белый интерфейс: Сегодня (что взять, что в работе), Лиды с фильтрами и шторкой лида, Отчёт
(лиды по дням, воронки, команда, здоровье источников), Контент (сделать, опубликовать, запланировать), Настройки.
Авторизация — подпись Telegram `initData`, доступ только владельцам и команде.

Telegram открывает Mini App только по публичному HTTPS. Два пути:
- `MINIAPP_TUNNEL=cloudflare` — бот сам поднимает бесплатный Cloudflare quick tunnel (без аккаунта и домена),
  ставит кнопку «Кабинет» в меню и раздаёт медиа для Threads/Instagram. Адрес меняется при перезапуске — для
  старта и теста достаточно.
- `MINIAPP_URL=https://leads.example.com/app` — свой домен (Caddy, nginx + certbot, именованный Cloudflare Tunnel).

`/app` в боте — кнопка открытия и подсказка, если кабинет не настроен. Локально без Telegram:
`python -m leadhunter.miniapp.dev <ваш_id> 8080`.

## Команды бота

**Группа и команда**: `/setup_group`, `/team`, `/team_del id`

**Лиды**: `/stats`, `/leads 20`, `/digest`, `/funnel 30 source|service|phrase|chat`, `/export`

**Фильтры**: `/rules`, `/rule_add +сайт +(нужен|ищу) -предлагаю` (словоформы учитываются; правило только из
`-слов` блокирует), `/rule_del id`, `/geo Москва, Тула`, `/keywords`, `/kw_add topic квиз сайт`, `/kw_del слово`,
`/threshold 6`, `/profile текст`, `/phrases`, `/phrases_set а; б; в`, `/phrases_gen`, `/template_set сайт текст`,
`/templates`, `/block @user`, `/unblock ключ`, `/ignored`, `/pause`, `/resume`

**Telegram-чаты**: `/tg_find фриланс заказы`, `/tg_join @chat`, `/tg_chats`, `/chats_rating` (какие чаты приносят
лидов), `/discover предприниматели` — бот ищет чаты по нише, читает последние 50 сообщений, оценивает «есть ли тут
заказчики» (словарь + ИИ) и вступает в лучшие, не больше 5 в день

**Контент**: `/post`, `/carousel`, `/reel`, `/toon`, `/aivideo`, `/magnet тема`, `/ideas [N]`, `/plan`, `/publish текст`, `/queue`,
`/show id`, `/schedule id дата время`, `/content`, `/channels`, `/channel_set`, `/channel_del`, `/voice`, `/brand`,
`/autopilot on|off` · `/niche [ключ]` · `/app`

**Состояние**: `/sources` — когда каждый источник последний раз опрашивался, сколько нашёл, что сломалось.
При капче или разлогине бот сам пришлёт алерт.

## Контент-фабрика

```
 /ideas, /plan ◀── боли клиентов из найденных лидов + рубрики ниши
      │
 /post /carousel /reel /toon /aivideo /magnet тема ──▶ ИИ (профиль + тон /voice + ваши правки «было → стало» + опубликованное)
      │
 карточка в боте: ✅ Опубликовать · 🗓 Когда · ✏️ Текст · 🔄 Переписать · 🎲 Вариант · 📦 Пакет · 🗑
      │
 Telegram-канал · VK · Threads · Instagram · YouTube Shorts  (по API)   |   TikTok, Дзен… (📦 Пакет: файлы + подпись)
```

- **Пост** — текст + обложка (ИИ-картинка Gemini, иначе брендированная обложка по шаблону).
- **Карусель** — 7–9 слайдов 1080×1350, рендер Pillow по шаблону с вашими цветами и подписью (`/brand`).
- **Видео** — вертикальный ролик 1080×1920 из сцен сценария (ffmpeg), озвучка Gemini TTS (бесплатно).
- **Мультик кодом** (`/toon`) — 2D-мультфильм с персонажами, эмоциями, диалогами в пузырях, фонами (офис, улица,
  дом), титрами и озвучкой. ИИ пишет сценарий, движок на Pillow + ffmpeg рисует его за секунды и **бесплатно**
  (20 секунд рендерятся ≈ 3 с). Без ИИ: `/toon Название | Директор: реплика | Разработчик: реплика`.
- **ИИ-мультик** (`/aivideo`) — видео генерирует нейросеть Gemini Omni клипами по 8–10 с с единым героем,
  склейка и озвучка — ffmpeg. Платно (≈ 0,07 $/сек ≈ 0,6 $ за клип), нужен биллинг в Google AI Studio.
- **Лид-магнит** — чек-лист/гайд + анонс + публичная страница `/lp/<slug>` с формой. Заявка с неё сразу
  становится лидом с баллом 9 и уходит в «🔥 Горячие» команде.
- **Обучение**: каждая правка через «✏️ Текст» или «🔄 Переписать» сохраняется как пара «было → стало» и
  попадает в промпт следующих генераций; опубликованные посты — образцы стиля.
- **Автопилот** (`/autopilot on`): каждый день в `CONTENT_HOUR` бот берёт идею из `/plan` (или придумывает по
  свежим запросам клиентов) и приносит черновик в тему «✍️ Контент». Публикует только после вашего ✅.
- **Расписание**: `🗓 Когда` → слоты, либо `/schedule id 2025-01-15 10:00`; `/queue` — что в очереди.
- **Без ИИ** работают `/publish текст`, `/carousel Заголовок | слайд | слайд`, `/reel фраза | фраза`, `/toon …`.

Площадки: `/channel_set telegram @канал` (бот — админ канала), `/channel_set vk -id_группы` + `VK_TOKEN`,
Threads (`THREADS_ACCESS_TOKEN` + `THREADS_USER_ID`), Instagram (`IG_ACCESS_TOKEN` + `IG_USER_ID`), YouTube
(`YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN`). Threads и Instagram принимают медиа только по публичным
ссылкам — нужен публичный адрес Mini App (туннель или домен), файлы раздаются с `/media/`.

### Что важно знать про площадки (состояние на ноябрь 2026)

- **YouTube Shorts**: монетизация — 1000 подписчиков + 10 млн просмотров Shorts за 90 дней (или 4000 часов);
  ранний доступ к фан-функциям — 500 подписчиков + 3 млн просмотров. С 01.02.2027 порог для новых — 20 млн.
  Квота API — ~100 загрузок в день. **Политика «inauthentic content» (с 16.07.2026)**: демонетизируются
  шаблонные ИИ-ролики без вариаций и ИИ-персонажи, «консультирующие» по финансам, праву и медицине. Поэтому
  бот делает авторские сценарии с конфликтом и развязкой, а не читает факты голосом; для реалистичных ИИ-визуалов
  включайте метку «AI-generated» при загрузке.
- **TikTok**: Content Posting API без аудита приложения публикует только в приватный режим; аудит занимает
  дни–недели. Поэтому TikTok — через «📦 Пакет» (видео + подпись, выкладка за минуту).
- **VK**: токен сообщества с 2026 года публикует **только текст** (фото/видео — error 27); для медиа нужен
  пользовательский токен с правами `wall,photos,video` (выдаются по запросу в поддержку VK). Бот это понимает:
  если медиа не загрузилось — публикует текст и предупреждает.
- **Instagram / Threads**: нужны бизнес-аккаунт и токены Meta; лимиты 100 и 250 постов в сутки соответственно.
- **Ритм**: Shorts 3–7 роликов в неделю, TikTok 5–7, Reels 4–7; хук в первые 1–2 секунды, крупные субтитры
  (смотрят без звука), один мастер-ролик на все площадки с разными хуками и подписями. Работают серийность и
  постоянные персонажи — `/brand` и `/toon` держат одних и тех же героев от ролика к ролику.

> **Про ключ ИИ**: подписка ChatGPT Plus **не даёт доступа к API**. Рекомендуем Gemini (aistudio.google.com):
> тексты и озвучка — бесплатный лимит, картинка ≈ 3 ₽, ИИ-видео ≈ 55 ₽ за клип 8 с. OpenAI-совместимые
> провайдеры (OpenAI, OpenRouter, DeepSeek) подходят для текстов; старые TTS-модели OpenAI закрываются в январе 2027.

## Фильтрация шума

- **Правила** `+сайт +(нужен|ищу|заказать) -предлагаю -курс` с лемматизацией (pymorphy3): «сайта/сайты/сайтик» = «сайт».
- **Гео**: `/geo Москва, Тула` — лид с другим городом в тексте отсекается, без города — остаётся.
- **Спам-детект**: один автор в 3 чатах за час — это рассылка исполнителя, автор уходит в игнор автоматически.
- **Семантический дедуп**: перефразированный повтор («салону нужен сайт, 30к» ≈ «нужен сайт для салона, бюджет 30к») не придёт второй раз.
- **Bio автора** (Telegram) подставляется в ИИ и карточку — видно, бизнес это или частник.

## Отправка сообщений клиентам

`TG_OUTREACH_LIMIT=15` включает кнопку «📨 Отправить с аккаунта»: черновик от ИИ уходит клиенту в личку с вашего
Telegram-аккаунта, не больше N в день. Больше 20–30 холодных сообщений в день с одного аккаунта — путь к бану,
поэтому лимит жёсткий. Для остальных площадок — кнопка «✍️ Черновик» и отправка руками.

## Как быстро приходят лиды

- Telegram — в момент публикации.
- Kwork, Threads, Freelance.ru, Weblancer, FL.ru — 5–15 минут.
- Яндекс.Карты и аудит — раз в 6 часов (это «холодная» база, а не поток).
- Поисковики — часы.

## Важно знать

- **Парсинг без API** живёт, пока площадка не поменяла вёрстку. Все парсеры покрыты тестами на реальной
  структуре страниц; если что-то сломается — `/sources` покажет ошибку, а бот пришлёт алерт.
- **Прокси**: из обычного домашнего/VPS IP всё работает (проверено из дата-центра). Если начались капчи —
  `PROXY_URL` с резидентным прокси.
- **Telegram**: аккаунт только для чтения и дозированных ответов. Лучше отдельный номер.
- **Instagram**: Meta банит автоматизацию. Только отдельный аккаунт, только с прокси.
- **ИИ**: любой OpenAI-совместимый API — OpenAI, OpenRouter, DeepSeek, Ollama. ~500 проверок/день на gpt-4o-mini — копейки.
- Все данные (сессии, профили браузера, база с лидами) лежат в `data/` и не коммитятся.
