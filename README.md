# LeadHunter — Telegram-бот для поиска лидов

Ищет людей и компании, которым нужны **сайты, Telegram-боты, ИИ-автоматизация, ИИ-мультики/ролики**, во всех
доступных местах и присылает их вам в Telegram: с оценкой, выжимкой от ИИ, бюджетом, контактом и готовым
черновиком первого сообщения.

## Как это работает

```
 Telegram-чаты ─┐
 Threads API ───┤
 Instagram API ─┤        ┌──────────┐   ┌──────────┐   ┌─────────┐   ┌─────────┐   ┌──────────┐
 Яндекс.Карты ──┼──────▶ │  дедуп   │─▶ │ игнор-   │─▶ │ словарь │─▶ │   ИИ    │─▶ │ карточка │
 FL.ru (RSS) ───┤        │ id+текст │   │ листы    │   │ скоринг │   │ GPT и т.п│   │ в Telegram│
 hh.ru ─────────┤        └──────────┘   └──────────┘   └─────────┘   └─────────┘   └──────────┘
 VK ────────────┤                                                        ▲
 Поисковики ────┘                                       ваши отметки «🔥 горячий / 🚫 не лид»
```

1. **Источники** работают параллельно, каждый со своим интервалом; Telegram — в реальном времени.
2. **Дедуп**: один и тот же запрос, разосланный по 10 чатам с разными ссылками и эмодзи, придёт один раз.
3. **Игнор-листы**: шумные чаты (кнопка «🔇 Чат в игнор» под карточкой) и авторы-спамеры (`/block @user`).
4. **Свежесть**: старше `MAX_AGE_HOURS` (48ч) — не показываем, там уже разобрали.
5. **Словарный скоринг** (мгновенный, бесплатный): тема +2/слово, намерение +3/слово, стоп-слова −3/слово.
   Слова по теме сгруппированы по услугам (сайт / бот / автоматизация / мультик) — карточка сразу показывает, что продавать.
6. **ИИ** (если задан `OPENAI_API_KEY`) смотрит всё, где есть хотя бы одно слово по теме, и возвращает:
   лид/не лид, балл 0–10, услугу, срочность, бюджет, выжимку одной строкой и **черновик первого сообщения**.
   В промпт подставляется **профиль вашей студии** (`/profile`) и **ваши последние отметки** 🔥/🚫 как примеры —
   ИИ подстраивается под ваш вкус без дообучения. Лимит вызовов в час защищает от счёта за токены.
   Если ИИ упал или лимит исчерпан — работает словарь, лид не теряется.
7. **Карточка** в Telegram: источник, балл, услуга, срочность 🔴🟡🟢, выжимка, текст, автор, контакт, бюджет,
   ссылка. Кнопки: ✅ Написал · 🔥 Горячий · 🚫 Не лид · ✍️ Черновик ответа · 🔇 Чат в игнор.
8. **Дайджест** раз в день (`DIGEST_HOUR`): сколько пришло, по источникам и услугам, топ неразобранных.

## Источники и как их подключить

| Источник | Что ищет | Задержка | Что нужно |
|---|---|---|---|
| **Telegram-чаты** | Все сообщения в группах, где состоит ваш аккаунт, + глобальный поиск по словам раз в 10 мин. Из бота можно искать чаты (`/tg_find`) и вступать (`/tg_join`) | секунды | `TG_API_ID`, `TG_API_HASH` → my.telegram.org → API development tools. Затем `python -m leadhunter.tg_login` |
| **Threads** | Свежие посты по фразам «нужен сайт», «ищу разработчика бота»… через официальный Keyword Search API | минуты | Приложение на developers.facebook.com с продуктом Threads, разрешения `threads_basic` + `threads_keyword_search` (второе проходит App Review). Лимит 2200 запросов/сутки — хватает с запасом |
| **Instagram** | Свежие посты по хэштегам `#нуженсайт`, `#ищуразработчика`… | минуты | Бизнес-аккаунт IG, привязанный к Facebook-странице; токен с `instagram_basic` + Instagram Public Content Access (App Review). Лимит 30 уникальных хэштегов в неделю — id кэшируются |
| **Яндекс.Карты** | Организации по запросам («салон красоты Москва») **без сайта** — с телефоном. Самый тёплый источник на сайты и ботов для записи | — | Бесплатный ключ Geosearch API на developer.tech.yandex.ru (500 запросов/сутки) |
| **Биржи (RSS)** | Заказы FL.ru (другие ленты — списком) | минуты | ничего |
| **hh.ru** | Проектные вакансии «разработка сайта», «telegram бот» | минуты | `HH_USER_AGENT` с реальной почтой |
| **VK** | `newsfeed.search` по фразам-намерениям по всем открытым постам | минуты | User-токен (vk.com/dev → Standalone-приложение → Implicit flow, права `wall`) |
| **Поисковики** | `site:vc.ru "нужен сайт"` и т.п. — для площадок без API | часы | Serper.dev (платный, 2500 запросов бесплатно) или DuckDuckGo без ключа |

Источник включается автоматически, если заполнены его ключи. Если есть официальный токен Threads/Instagram,
эти домены убираются из поиска через поисковики.

## Запуск

```bash
cp .env.example .env     # заполнить BOT_TOKEN и ключи нужных источников
pip install .
python -m leadhunter.tg_login   # один раз: вход в Telegram-аккаунт (телефон + код)
python -m leadhunter
```

Или в Docker:

```bash
docker compose run --rm -it leadhunter python -m leadhunter.tg_login
docker compose up -d
```

Напишите боту `/start` — первый написавший становится владельцем (или задайте `OWNER_IDS`).

## Команды бота

**Лиды**: `/stats`, `/leads 20`, `/digest`, `/export` (CSV для Excel/Google Sheets)

**Фильтры**: `/keywords`, `/kw_add topic квиз сайт`, `/kw_del слово`, `/threshold 6`, `/profile текст`,
`/block @user`, `/unblock ключ`, `/ignored`, `/pause`, `/resume`

**Telegram-чаты**: `/tg_find фриланс заказы` → список публичных чатов, `/tg_join @chat`, `/tg_chats`

**Состояние**: `/sources` — когда каждый источник последний раз опрашивался и что сломалось

## Как быстро приходят лиды

- Telegram — в момент публикации (realtime через аккаунт).
- Threads / Instagram / VK / FL.ru / hh — через 5–15 минут после публикации (интервал опроса настраивается).
- Поисковики — часы (пока пост проиндексируется). Это запасной путь для площадок без API.

## Важно знать

- **Telegram**: бот не может читать чужие чаты, поэтому мониторинг идёт через ваш аккаунт. Используйте его
  только для чтения — автоответы и рассылки с него быстро приводят к бану. Лучше отдельный номер.
  Бот специально **не пишет клиентам сам**: он даёт черновик, вы отправляете его со своего аккаунта.
- **Threads/Instagram**: прямой парсинг нарушает правила и ломается каждую неделю, поэтому только официальные
  API. Оба требуют App Review у Meta (обычно 1–2 недели). До одобрения работает путь через поисковики.
- **hh.ru** отвечает 403 на запросы из некоторых дата-центров и на User-Agent без контакта.
- **ИИ**: подходит любой OpenAI-совместимый API — OpenAI, OpenRouter, DeepSeek, локальный Ollama
  (`OPENAI_BASE_URL=http://localhost:11434/v1`). При ~500 проверках в день на gpt-4o-mini это копейки.
- Все данные (сессия Telegram, база с лидами) лежат в `data/` и не коммитятся.
