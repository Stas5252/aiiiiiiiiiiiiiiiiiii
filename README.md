# LeadHunter — Telegram-бот для поиска лидов

Ищет людей и компании, которым нужны **сайты, Telegram-боты, ИИ-автоматизация, ИИ-мультики/ролики**, и присылает их вам в Telegram с кнопками «написал / горячий / не лид».

## Откуда берёт лидов

| Источник | Как работает | Что нужно |
|---|---|---|
| **Telegram-чаты** | Ваш аккаунт (Telethon) читает все группы, где состоит, в реальном времени + раз в 10 мин делает глобальный поиск по словам «сайт», «бот», «нейросеть»… | `TG_API_ID`, `TG_API_HASH` с my.telegram.org |
| **Яндекс.Карты** | Берёт организации по запросам («салон красоты Москва») и отдаёт те, у кого **нет сайта** — с телефоном | бесплатный ключ Geosearch API |
| **Биржи (RSS)** | FL.ru отдаёт заказы в RSS; можно добавить любые другие RSS-ленты | ничего |
| **hh.ru** | Проектные вакансии «разработка сайта», «telegram бот» через публичный API | только User-Agent с почтой |
| **VK** | `newsfeed.search` по фразам «нужен сайт», «ищу разработчика бота»… по всем открытым постам | user-токен VK |
| **Threads, Instagram, vc.ru, Pikabu** | У них нет бесплатного поиска по постам, поэтому ищем свежие публичные посты через поисковик `site:threads.net "нужен сайт"` | ключ serper.dev (или бесплатный DuckDuckGo без ключа) |

Источник включается автоматически, если заполнены его ключи. Все лиды проходят один пайплайн:
дедуп (по id и по тексту — один запрос, разосланный по 10 чатам, придёт один раз) → скоринг по ключевым словам
→ (опционально) проверка ИИ → сохранение в SQLite → уведомление.

## Запуск

```bash
cp .env.example .env     # заполнить BOT_TOKEN и ключи нужных источников
pip install .
python -m leadhunter.tg_login   # один раз: вход в Telegram-аккаунт (телефон + код)
python -m leadhunter
```

Или в Docker:

```bash
docker compose run --rm -it leadhunter python -m leadhunter.tg_login
docker compose up -d
```

Напишите боту `/start` — первый написавший становится владельцем (или задайте `OWNER_IDS`).

## Команды бота

- `/stats` — лиды за сутки по источникам
- `/leads 20` — последние лиды
- `/keywords`, `/kw_add topic|intent|negative слово`, `/kw_del слово` — управление словарём
- `/threshold 6` — минимальный балл для уведомления (0–10)
- `/pause`, `/resume` — пауза уведомлений (лиды продолжают копиться)
- `/sources` — что включено

## Как считается балл

- **Тема** (сайт, лендинг, бот, автоматизац, нейросет, мультик, анимац…) — +2 за слово, макс 6
- **Намерение** (ищу, нужен, кто сделает, посоветуйте, бюджет…) — +3 за слово, макс 6
- **Стоп-слова** (сделаю, разработаю, портфолио, резюме, курс…) — −3 за слово: отсекают конкурентов и рекламу
- Для бирж и hh намерение подразумевается; для Яндекс.Карт балл фиксированный (6)

Если задать `OPENAI_API_KEY`, прошедшие порог лиды дополнительно проверяет модель: отбрасывает мусор,
ставит 0–10 и пишет одной строкой, что нужно клиенту.

## Важно знать

- **Telegram**: бот не может читать чужие чаты, поэтому мониторинг идёт через ваш аккаунт. Используйте его только для чтения — автоответы и рассылки с него быстро приводят к бану. Лучше отдельный номер.
- **Instagram/Threads** официально не дают искать посты; прямой парсинг нарушает их правила и ломается каждую неделю. Поиск через поисковики — легальный и стабильный путь, но находит только проиндексированные посты (задержка часы, а не минуты).
- **hh.ru** отвечает 403 на запросы из некоторых дата-центров и на User-Agent без контакта.
- **Яндекс.Карты**: бесплатный ключ — 500 запросов/сутки; при 2 городах × 6 запросах × 2 страницах хватает на 4 прогона в день.
- Все данные (сессия Telegram, база с лидами) лежат в `data/` и не коммитятся.
