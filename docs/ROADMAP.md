# LeadHunter — план доведения до рабочего продукта

Исходная точка: аудит от 23.11.2026 (`docs/audit/00_summary.md`): 211 тестов проходят, 95 замечаний (7 критичных, 47 важных, 41 мелочь).

## Целевая картина

1. **Поиск лидов.** Надёжные источники (Kwork, Weblancer, FL.ru, Freelance.ru, Яндекс.Карты, Telegram-чаты), честный статус каждого источника, алерт при поломке.
2. **Умный анализ лида.** По каждому лиду — досье: сайт (скорость, мобильная версия, HTTPS, SEO-теги, структура), конкуренты в том же городе и нише, гео, оценка бюджета, готовое персональное предложение. ИИ обязателен, словарь — только запасной вариант.
3. **Кабинет и бот.** Безопасные роли, понятные ошибки, ничего не теряется и не дублируется.
4. **Контент-фабрика.** Посты, карусели, ролики, мультики, лид-магниты; публикация без дублей; расписание и автопилот; контент-план.
5. **Нарезки для YouTube/Shorts.** Длинное видео → вертикальные клипы с субтитрами, заголовком и описанием от ИИ → очередь публикации.
6. **Установка за 5 минут.** `install.sh`, Docker и `.env.example` работают с первого раза.
