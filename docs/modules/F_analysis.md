# F. Умный анализ лида (волна 2)

Цель: к каждому стоящему лиду — досье, по которому можно сразу писать клиенту.

Что входит в досье:
1. **Сайт**: доступность, HTTPS и сертификат, мобильная версия, скорость (размер страницы, время ответа), `title`/`description`/`h1`, `robots.txt`, `sitemap.xml`, микроразметка, битые ссылки на главной, формы и контакты, CMS/конструктор, год в футере.
2. **SEO**: по каким запросам сайт виден в выдаче по своей нише и городу (через уже подключённые поисковые источники), чего не хватает.
3. **Конкуренты**: 3–5 организаций той же рубрики и города с карт, их сайты и тот же технический разбор — таблица «клиент против конкурентов».
4. **Гео**: город, район, филиалы, охват.
5. **Вывод ИИ**: что болит, что предложить, оценка чека, вероятность сделки, готовое первое сообщение в тоне владельца.

Требования:
- Новый пакет `leadhunter/analysis/`; запуск автоматически для лидов выше порога и по кнопке «Досье» в карточке и кабинете; результат хранится в базе и показывается в кабинете.
- Без ключа ИИ — технический разбор без вывода, с явной пометкой.
- Лимиты запросов и кэш по домену; только открытые страницы, `robots.txt` уважается.
- Тесты на сохранённых HTML-фикстурах и моках ИИ.
