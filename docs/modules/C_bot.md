# C. Бот и безопасность

Цель: доступ только у тех, кому положено; ключи нигде не светятся; ни одна команда не падает молча.

Находки: `docs/audit/02_bot_miniapp.md` V1, V2, V4–V10, V17, V19, M5–M10, M11 (часть про сброс состояния — совместно с E, файл `bot/content.py` у E).

Главное:
- V1 владелец по первому `/start`: требовать `OWNER_IDS` или одноразовый код из лога/консоли; анонимный админ не может стать владельцем.
- V2 перепроверка членства в рабочей группе.
- V4–V6, V9 секреты: прокси как секрет, `httpx` не пишет токены в лог, ошибки не возвращают ключ, ключи принимать только в личке.
- V7–V8 состояния ввода сбрасываются командами и по таймауту.
- V17 длинные ответы режутся на части, все поля экранируются.
- V19 фоновые задачи логируют падение; туннель перезапускается и обновляет кнопку.

Готово, когда: на каждую находку есть тест через `Dispatcher.feed_update` с подменённой сессией; 54 команды и кнопки чужому по-прежнему не отвечают.
