# A. Установка и запуск

Цель: человек без опыта ставит бота одной командой, и он стартует с первого раза в Docker и в Python-режиме.

Находки: `docs/audit/03_content_install.md` № 1, 2, 6, 7, 8, 9, 31, 32, 33; `docs/audit/01_leads.md` № 5 (hh.ru включён по умолчанию), № 21 (проверка `DIGEST_TZ`/`DIGEST_HOUR` при запуске).

Замечание: № 5 (CRLF и нет `+x`) — след упаковки архива, в git файлы с LF и `100755`. Добавьте `.gitattributes` (`*.sh text eol=lf`), чтобы это не повторилось.

Готово, когда:
- `cp .env.example .env` + фиктивный `BOT_TOKEN` → `Settings()` создаётся и в Python, и через `docker compose config`/`run`; тест на это в `tests/`.
- Пустые значения в `.env` не роняют запуск; неверные дают понятное сообщение на русском.
- `install.sh` и `update.sh` проходят ShellCheck и прогон в чистом контейнере Ubuntu (без `curl`, без systemd, от root).
- README соответствует коду: команда установки, цифры, список переменных.
