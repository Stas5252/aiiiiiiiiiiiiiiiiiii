# G. Нарезки для YouTube и Shorts (волна 2)

Цель: длинное видео (игровая запись, стрим, обзор) → несколько вертикальных клипов, готовых к публикации.

Конвейер:
1. Вход: файл или ссылка на видео, на которое у владельца есть права (свои записи игр и стримов, материалы с разрешением автора).
2. Распознавание речи → поиск ярких моментов (ИИ по расшифровке + громкость/смена сцен).
3. Нарезка `ffmpeg`: 9:16, кадрирование по центру действия, субтитры по словам, заголовок-хук в первые секунды.
4. ИИ пишет название, описание, теги; обложка — существующий рендер.
5. Клипы попадают в очередь контент-фабрики: предпросмотр в боте и кабинете → расписание → YouTube и другие площадки через существующих публикаторов.

Требования:
- Новый модуль `leadhunter/content/clips.py`, команда `/clips`, раздел в кабинете.
- Работа без GPU; длинные задачи — в фоне с прогрессом.
- Перезалив чужих видео без прав и обход защит площадок не делаем: это блокировка канала и нарушение авторских прав.
- Тесты на коротком синтетическом видео.

Открытый вопрос к владельцу: откуда берётся исходное видео.
