# Правила для агентов (и людей), работающих над LeadHunter

Цель проекта: бот, который реально приносит заказы и ведёт соцсети — умный поиск и анализ лидов с ИИ, контент-фабрика (посты, карусели, ролики, нарезки), кабинет в Telegram.

## Как устроена работа

- Интеграционная ветка — `dev`. В `main` никто не пушит.
- Один модуль — один агент — одна ветка `devin/<время>-<модуль>` от `dev` — один PR в `dev`.
- План и статусы: `docs/ROADMAP.md`. Задание модуля: `docs/modules/<модуль>.md`. Исходные находки аудита: `docs/audit/`.
- Трогайте только файлы своего модуля (список в задании). Если нужна правка в чужом файле — минимальная, и отдельным пунктом в описании PR.
- Управляющий агент сводит PR, решает конфликты и раздаёт следующие задания.

## Обязательные правила

1. Настоящий `BOT_TOKEN` и рабочую базу не использовать. Тесты — на фиктивном токене, моках и временной SQLite (см. `tests/test_bot_e2e.py`).
2. Секреты не коммитить и не печатать в логи, PR и отчёты. `.env`, `data/`, `*.session` — в `.gitignore`.
3. Каждое исправление — с тестом, который падал до правки. `pytest` должен проходить целиком.
4. Живые запросы к площадкам — одиночные, с паузами; в тестах только сохранённые фикстуры и моки.
5. Обход защит, чужие аккаунты, массовые рассылки и перезалив чужого видео без прав не реализуем.
6. Тексты для пользователя — на русском, простыми словами. Новые настройки — в `.env.example` (комментарий отдельной строкой над переменной) и в README.
7. Зависимости — только проверенные и только при необходимости; добавлять в `pyproject.toml`.

## Запуск

```bash
python3.12 -m venv .venv && . .venv/bin/activate && pip install -e ".[dev]"
pytest
python -m leadhunter.miniapp.dev 1 8080   # кабинет локально, без Telegram
python scripts/seed_dev.py                 # тестовые лиды из живых источников (на копии базы)
```

## Что сдавать

PR в `dev`: что исправлено (номера находок из `docs/audit/`), что добавлено, как проверено (команды и вывод), что не удалось проверить и почему. В конце работы — обновить свою строку в `docs/ROADMAP.md`.
